# 📜 FORGE OS V6 Changelog

## [6.0.0] - 2026-07-31

### Added
- **Commercial Auth Suite**: Integrated JWT authentication and user registration (`backend/api/auth.py`).
- **Feature-First Architecture**: Refactored frontend structure into modular feature domains (`src/features/director`, `src/features/leads`, `src/features/missions`, `src/features/health`).
- **React 19 + R3F + Zustand + TanStack Query Stack**: Complete modern stack with Three.js 3D spatial radar globe.
- **Settings Store**: Added persistent settings management for AI Provider API Keys (`backend/api/settings.py`).
