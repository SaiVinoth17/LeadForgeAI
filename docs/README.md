# ⚡ FORGE OS V6 — Commercial Production Manual

FORGE OS V6 is an autonomous, GPU-accelerated AI Operating System designed for web agencies, freelancers, and growth teams.

## 🚀 Features

- **Proactive AI Director Engine**: Ranks highest-impact revenue targets daily.
- **Digital Twin Client Memory**: Stores persistent website audit histories, SEO metrics, and buying intent.
- **React Three Fiber 3D Spatial Radar**: High-speed WebGL spatial opportunity radar.
- **FastAPI Asynchronous Backend**: Modular API router serving OpenAPI Swagger UI `/docs`.
- **Commercial Auth & Security**: JWT Authentication, password hashing, and encrypted settings store.

## 📦 Production Quick Start

```bash
# Backend Setup
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py

# Frontend Setup
cd frontend
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.
