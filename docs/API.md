# 🔌 FORGE OS V6 OpenAPI & Endpoint Reference

Swagger UI documentation is available live at: `http://127.0.0.1:49281/docs`

## Endpoint Catalog

- `GET /api/v5/director`: Proactive AI Director Recommendation.
- `GET /api/v5/leads`: Lead Digital Twin profiles and scores.
- `POST /api/v5/copilot/action`: Copilot action trigger.
- `GET /api/v5/missions`: Active Agency acquisition missions.
- `GET /api/v5/health`: AI provider latency telemetry.
- `POST /api/v5/auth/login`: JWT login endpoint.
- `POST /api/v5/auth/register`: User registration endpoint.
- `GET /api/v5/settings`: Settings retrieval & persistence.
- `WS /ws/v5/stream`: Real-time WebSocket event stream.
