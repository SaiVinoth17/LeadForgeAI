# LeadForge AI

LeadForge AI is a modern CRM and Lead Generation platform tailored for freelance web developers and digital agencies. 

Powered by OpenStreetMap, Python 3, and AI heuristics, LeadForge AI allows you to discover businesses, analyze their web presence, and automatically generate tailored sales pitches—all without expensive API subscriptions.

## Features (v2.0)
- **OpenStreetMap Integration**: 100% free lead discovery (Nominatim + Overpass). No Google API keys needed.
- **Automated Website Analyzer**: Checks SSL, responsiveness, frameworks, SEO tags, and robots.txt.
- **Sales Intelligence**: Generates automated Proposals, Emails, and WhatsApp drafts tailored to the business's weaknesses.
- **Playwright Screenshots**: Captures automated Desktop and Mobile screenshots for your pitches.
- **Visual Dashboard**: Matplotlib integration for real-time analytics.
- **Map View**: Interactive offline-ready map view using OpenStreetMap tiles.

## Installation
Run `python build.py` to generate a standalone Windows executable.
If running from source, use `pip install -r requirements.txt`.
