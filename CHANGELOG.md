# Changelog

## [2.0.0] - 2026-07-20
### Added
- OpenStreetMap and Nominatim Integration (replaced Google APIs).
- `tkintermapview` integration for visual Map View.
- Matplotlib charts on Dashboard.
- Playwright Headless Screenshot Engine (Mobile & Desktop).
- Automated AI Proposal, Email, and WhatsApp Generators.
- Comprehensive Website Analyzer with Framework and SEO detection.
- Toast Notifications for robust user feedback.
- PyInstaller standalone Windows executable build script.

### Changed
- CRM completely overhauled with bulk action checkboxes and dynamic sorting.
- UI styling updated to Premium Dark UI with custom colors and fonts.
- Settings page supports fallback APIs, branding options, and screenshot retention intervals.

### Removed
- Removed default Google Billing dependencies.
